# Palpi — приложение для задач

Простой список дел, как у приложений на iPhone: добавить задачу, отметить сделанной и удалить.

Есть две версии:

1. **Настоящее приложение для iPhone** — папка `ios/Palpi`. Его открывают в Xcode на Mac.
2. **Макет в браузере** — папка `web`. Его можно сразу открыть на компьютере или в Safari на iPhone.

Обе версии умеют одно и то же: список задач сохраняется на устройстве и не пропадает после обновления страницы.

## Что можно делать

- Добавить задачу
- Отметить её выполненной (нажать на кружок)
- Удалить задачу
- Смотреть фильтры: Все / Активные / Готово

## Как открыть макет в браузере

```bash
cd web
python3 -m http.server 4173
```

Затем откройте [http://localhost:4173](http://localhost:4173).

На iPhone: откройте тот же адрес в Safari. Чтобы иконка появилась на экране «Домой», нажмите «Поделиться» → «На экран Домой».

## Как открыть настоящее iPhone-приложение

1. На Mac установите [Xcode](https://developer.apple.com/xcode/).
2. Откройте `ios/Palpi/Palpi.xcodeproj`.
3. Выберите симулятор iPhone и нажмите Run (▶).

Нужен iOS 17 или новее.

## Как устроен код

Для новичка достаточно трёх идей:

- **Модель** — что такое задача (`title`, сделана или нет).
- **Хранилище** — добавляет, переключает, удаляет и сохраняет список.
- **Экран** — показывает список и кнопки.

В iOS это файлы `TaskItem.swift`, `TaskStore.swift` и `TaskListView.swift`.
В вебе — `store.js` и `app.js`.

## Тесты

Проверка логики веб-версии (без браузера):

```bash
cd web
npm test
```

Тесты для iPhone-приложения запускаются в Xcode: `Product → Test`.
